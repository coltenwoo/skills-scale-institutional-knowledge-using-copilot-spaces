# OctoAcme Project Management Docs

This README provides an overview and links to all project management process documentation used by OctoAcme.

## Summary of Project Management Processes

OctoAcme project management emphasizes clear ownership, iterative delivery, and data-informed decision-making. Core practices include:

- **Project initiation** with one-pager, stakeholder alignment, and success metrics
- **Planning** with prioritized backlog, milestone mapping, risk management, and definition of done
- **Execution** with daily standups, PR workflow, QA/testing, and demo/review cadence
- **Release and deployment** with pre-release requirements, deployment checklist, and incident playbook
- **Continuous improvement and retrospective** with actionable action items
- **Risk management** and transparent stakeholder communication
